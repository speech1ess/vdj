## Введение

**Playlist AI** — это инструмент для создания персонализированных музыкальных плейлистов. Программа сканирует каталог аудиофайлов, извлекает метаданные, такие как BPM, жанр и музыкальный ключ, и генерирует плейлисты на основе ваших предпочтений.

---

## Установка

### Зависимости

1. **Python 3.x**.
2. **Библиотеки**:
   - `mutagen`, `librosa`, `tqdm`, `tkinter`, `sqlite3`, `psycopg2`.

   Установите все зависимости с помощью команды:

   ```bash
   pip install -r requirements.txt
   ```

### Установка и запуск

1. Скачайте или клонируйте репозиторий.
2. Запустите главный файл:

   ```bash
   python main.py
   ```

3. Следуйте инструкциям на экране для выбора каталога с аудиофайлами, формата сохранения и других настроек.

## Настройка конфигурации
### Общая информация

Конфигурация Playlist AI хранится в файле `config.json` и содержит настройки для:
- Типа базы данных
- Путей к директориям для хранения данных и SQL-скриптов
- Параметров подключения к базам данных

При первом запуске приложения создается файл конфигурации с настройками по умолчанию.

### Типы баз данных

Playlist AI поддерживает следующие типы баз данных:

#### CSV

Простой формат хранения данных в текстовых файлах с разделителями. Подходит для небольших коллекций и экспорта данных в другие приложения, не требует дополнительного ПО.

**Параметры конфигурации:**
- `delimiter` - разделитель полей (по умолчанию ",")
- `encoding` - кодировка файла (по умолчанию "utf-8")
- `quotechar` - символ для обрамления полей (по умолчанию '"')

#### SQLite

Встраиваемая локальная СУБД, которая хранит данные в одном файле. Подходит для средних коллекций и обеспечивает базовые возможности SQL.

**Параметры конфигурации:**
- `db_path` - путь к файлу базы данных
- `timeout` - таймаут операций в секундах (по умолчанию 20)

#### PostgreSQL

Полноценная СУБД для больших коллекций, обеспечивающая высокую производительность и расширенные возможности SQL.

**Параметры конфигурации:**
- `host` - хост сервера PostgreSQL
- `port` - порт сервера PostgreSQL
- `dbname` - имя базы данных
- `user` - имя пользователя
- `password` - пароль
- `ssl_mode` - режим SSL (по умолчанию "prefer")
- `connection_timeout` - таймаут подключения в секундах (по умолчанию 30)

### Настройка через GUI

Playlist AI предоставляет графический интерфейс для настройки конфигурации:

1. Запустите приложение
2. Нажмите кнопку "Конфигуратор"
3. Выберите тип базы данных из выпадающего списка
4. Нажмите "Сохранить настройки" для настройки путей и параметров подключения
5. Для проверки конфигурации нажмите "Проверить конфигурацию"
6. Для проверки соединения с базой данных нажмите "Проверить соединение"

### Пример конфигурации

Конфигурация хранится в файле `config.json` и может быть изменена через графический интерфейс или напрямую.
```json
{
  "db_type": "postgresql",
  "output_dir": "C:/Users/username/Documents/PLG/data",
  "sql_scripts_dir": "C:/Users/username/Documents/PLG/sql",
  "db_config": {
    "host": "localhost",
    "port": "5432",
    "dbname": "PLG",
    "user": "plg",
    "password": "plg"
  }
}
```

### Настройка директорий

Для настройки директорий хранения данных и SQL-скриптов:
1. В окне "Конфигуратор" нажмите "Сохранить настройки"
2. Выберите директорию для сохранения данных
3. Если выбран тип базы данных SQLite или PostgreSQL, выберите директорию с SQL-скриптами

### Настройка подключения к PostgreSQL

Если вы выбрали PostgreSQL в качестве типа базы данных:
1. После выбора директорий вам будет предложено ввести параметры подключения:
   - Хост (по умолчанию localhost)
   - Порт (по умолчанию 5432)
   - Имя базы данных
   - Имя пользователя
   - Пароль
2. После ввода параметров нажмите "ОК"
3. Для проверки соединения нажмите кнопку "Проверить соединение"
4. Для создания необходимых таблиц нажмите кнопку "Создать БД"

### Проверка конфигурации

Чтобы проверить текущие настройки:
1. В окне "Конфигуратор" нажмите кнопку "Проверить конфигурацию"
2. Откроется окно с текущими настройками в виде дерева параметров

## Использование

### Шаг 1: Выбор каталога с аудиофайлами

После запуска программы вам будет предложено выбрать каталог с аудиофайлами. Это можно сделать через диалоговое окно, в котором вы можете указать папку с MP3, FLAC или другими поддерживаемыми форматами.

### Шаг 2: Сканирование и сохранение результатов

Выберите, в каком формате вы хотите сохранить данные:
- **CSV**: для экспорта в таблицы или другие приложения.
- **SQLite**: для локальной базы данных.
- **PostgreSQL**: для работы с удалённой базой данных.

### Шаг 3: Настройка плейлиста

Программа предложит вам выбрать параметры для генерации плейлиста, такие как:
- **BPM**: темп музыки.
- **Жанр**.
- **Музыкальный ключ**.
- **Длительность плейлиста**.

Вы можете фильтровать треки по этим параметрам для создания плейлиста, который идеально соответствует вашим предпочтениям.

### Шаг 4: Создание плейлиста

После того как все параметры выбраны, программа сгенерирует плейлист и предложит сохранить его в выбранном формате.

## Примеры использования

### Пример 1: Генерация плейлиста с фильтром по BPM

1. Выберите каталог с аудиофайлами.
2. Выберите формат сохранения как **CSV**.
3. Установите фильтр по BPM, например, "120-140".
4. Программа сгенерирует плейлист с треками в этом диапазоне BPM.

### Пример 2: Создание плейлиста по жанру и музыкальному ключу

1. Выберите каталог с аудиофайлами.
2. Выберите формат сохранения как **SQLite**.
3. Установите фильтры по жанру (например, "Поп") и ключу (например, "C Major").
4. Программа создаст плейлист, соответствующий этим фильтрам.
