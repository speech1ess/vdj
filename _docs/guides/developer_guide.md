## Введение

**Playlist AI** разработан с учётом простоты расширения и модификации. Если вы хотите внести изменения в код, добавить новые функции или улучшить существующие, этот раздел поможет вам разобраться в структуре проекта и предоставит необходимые инструкции.

---

## Структура проекта

```
playlist_ai/
│
├── back.py              # Логика работы с БД, CSV и запросами: создание таблиц, выборка и сохранение данных
├── conf.py              # Модуль конфигуратора для пользовательских настроек и выбора формата
├── config.json          # Конфигурационный файл с параметрами подключения к БД
├── gen.py               # Генерация плейлистов на основе пользовательских предпочтений
├── gui.py               # Модуль интерфейса
├── main.py              # Скрипт для запуска
├── README.md            # Описание
├── scan.py              # Процессинг аудио: сканирование каталога и извлечение метаданных
├── sql/                 # Папка для SQL-скриптов для создания БД (SQLite, PostgreSQL)
│   ├── sqlite_tables.sql# SQL-скрипт для создания базы данных SQLite
│   └── pg_tables.sql    # SQL-скрипт для создания базы данных PostgreSQL
├── docs/                # Документация
│   ├── classes/         # Документация по классам
│   │   └── Configurator.md # Документация для класса Configurator
│   ├── developer_guide.md  # Документация для разработчиков
│   └── user_guide.md    # Руководство пользователя
├── examples/                # Примеры использования
│   └── Configurator.examples.py # Примеры использования класса Configurator
└── requirements.txt     # Список зависимостей
```

## Описание модулей

### **`gui.py`**

Модуль графического интерфейса приложения, отвечает за взаимодействие с пользователем. Включает классы:
-  [`GUI`](classes/GUI.md): Класс для ...
-  [`ConfiguratorGUI`](classes/ConfiguratorGUI.md): Класс для ...
-  [`ScanGUI`](classes/ScanGUI.md): Класс для ...
-  [`ManagerGUI`](classes/ManagerGUI.md): Класс для ...
-  [`GeneratorGUI`](classes/GeneratorGUI.md): Класс для ...

### **`conf.py`**

Модуль конфигуратора для настройки параметров, отвечает за управление настройками приложения, включая тип базы данных, пути к директориям и параметры подключения к БД. Включает классы:
- [`Configurator`](classes/Configurator.md): Класс для управления настройками приложения, включая тип базы данных, пути к директориям и параметры подключения к БД.

### **`scan.py`**

Модуль обработки аудио-файлов. Включает классы:
-  [`SoundScanner`](classes/SoundScanner.md): Класс для ...

### **`backend.py`**

Модуль для работы с базой данных и CSV:
-  [`Backend`](classes/Backend.md): Класс для ...

### **`gen.py`**

Отвечает за генерацию плейлистов:
- `generate_playlist()`: Создаёт плейлист на основе данных о треках.
- `filter_tracks_by_bpm()`: Фильтрует треки по BPM.

### Описание классов и их методов

| Модуль            | Класс              | Метод                | Описание                                      |
|-------------------|--------------------|----------------------|----------------------------------------------|
| **`back.py`**     | Backend            | `save_to_csv()`      | Сохраняет данные в файл CSV.                 |
|                   |                    | `save_to_sqlite()`   | Сохраняет данные в локальную SQLite базу данных. |
|                   |                    | `save_to_postgres()` | Сохраняет данные в PostgreSQL базу данных.   |
| **`configurator.py`** | Configurator   | `set_audio_folder()` | Запрашивает и устанавливает путь к папке с аудиофайлами. |
|                   |                    | `ask_save_format()`  | Запрашивает формат для сохранения данных (CSV, SQLite, PostgreSQL). |
|                   |                    | `ask_db_config()`    | Запрашивает параметры для подключения к PostgreSQL. |
|                   |                    | `ask_save_directory()` | Запрашивает каталог для сохранения данных. |
| **`gui.py`**      | GUI                | `create_window()`    | Создает основное окно приложения.            |
|                   |                    | `set_audio_folder()` | Выбирает папку для аудиофайлов.               |
|                   |                    | `ask_save_format()`  | Осуществляет выбор формата сохранения.        |
|                   |                    | `ask_db_config()`    | Осуществляет настройку подключения к БД.      |
|                   |                    | `generate_playlist()` | Генерирует плейлист по заданным критериям.    |
| **`gen.py`**      | PlaylistGenerator  | `generate_playlist()` | Генерирует плейлист на основе запроса пользователя. |
|                   |                    | `filter_tracks_by_bpm()` | Фильтрует треки по BPM.                        |
| **`scan.py`**     | SoundScanner       | `scan_audio_files()` | Сканирует каталог и собирает все аудиофайлы.  |
|                   |                    | `extract_metadata()` | Извлекает метаданные (артист, название, жанр). |
|                   |                    | `analyze_bpm_key()`  | Анализирует BPM и ключ аудиофайла.             |
| **`main.py`**     | -                  | `main()`             | Запускает программу.                          |
|                   |                    | `create_menu()`      | Создает меню для выбора действий.             |

## Тестирование

Для тестирования проекта используется модуль **unittest**. Тесты для каждого модуля находятся в отдельной папке **tests**.

Пример команды для запуска тестов:

```bash
python -m unittest discover -s tests
```

## Развёртывание

Для развертывания проекта на сервере или в облаке:
1. Убедитесь, что установлены все зависимости через `pip install -r requirements.txt`.
2. Настройте конфигурацию подключения к базе данных в файле `config.json`.
3. Запустите приложение с помощью:

   ```bash
   python main.py
   ```
