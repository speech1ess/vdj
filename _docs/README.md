
# Документация Playlist AI

## Описание

В этой папке хранится вся документация по проекту **Playlist AI**, включая:
- Архитектурные решения.
- Диаграммы C4.
- Руководства по установке и настройке.
- Прочую техническую документацию и файлы.

## Описание разделов

### 1. `adr/` — Architectural Decision Records
Здесь находятся записи о ключевых архитектурных решениях. 
Каждый ADR включает:
- **Контекст** — описание проблемы или требования.
- **Решение** — принятое архитектурное решение.
- **Альтернативы** — рассмотренные альтернативные решения.
- **Последствия** — плюсы и минусы выбранного решения.

#### `templates/`
- **Шаблон ADR (`adr_template.md`)** — Используйте этот шаблон для добавления новых ADR.

#### `yaml/`
- Конфигурации YAML для генерации ADR с использованием **generate_adr.py**.

---

### 2. `diagrams/` — Диаграммы архитектуры (C4-модель)
Диаграммы, созданные в соответствии с **C4-моделью визуализации архитектуры**:
- **C1.context** — Контекст системы, взаимодействие с внешними системами.
- **C2.container** — Контейнеры, их назначение и взаимодействие.
- **C3.component** — Компоненты внутри контейнеров и их зависимости.

---

### 3. `guides/` — Руководства и мануалы
Документация по установке и настройке системы DSHM:
- **User_Guide.html** — Руководство пользователя.
- **Admin_Guide.html** — Руководство администратора.

---

### 4. `files/` — Прочие файлы документации
- Хранение файлов в других форматах, таких как **DOC** и **PDF**.
- Используются для внешней документации, технических спецификаций и презентаций.
