# ADR 0003: Использование Librosa и Mutagen для анализа аудио

## Контекст
Playlist AI требует анализа аудиофайлов для извлечения характеристик треков, необходимых для генерации треклистов: BPM, тональность, энергетика, настроение и длительность. Дополнительно нужны базовые метаданные (название, исполнитель, альбом) для отображения и хранения. В MVP важны точность, простота установки и совместимость с Python. На данный момент сканирование треков реализовано, результаты экспортируются в CSV с полями `bpm` и `key`, что указывает на использование инструментов анализа. Модель Track включает поля `bpm`, `key`, `energy_level`, `mood`, `duration`, соответствующие требованиям SRS.


## Решение
Использовать **Librosa** и **Mutagen** для анализа аудио:
- **Librosa**: Основной инструмент для анализа аудиосигналов, извлекает `bpm`, `key`, `energy_level`, `mood` через спектральные характеристики и алгоритмы (например, темп через onset detection, тональность через chroma features).
- **Mutagen**: Используется для извлечения метаданных (`title`, `artist`, `album`) и длительности (`duration`) из тегов аудиофайлов (MP3, FLAC и т.д.).
Интеграция с моделями SQLAlchemy (Track, AudioFile) позволяет сохранять результаты анализа в БД и экспортировать в CSV.


## Альтернативы

- **Essentia** — Мощный инструмент для анализа аудио, но сложнее в установке (требует сборки) и избыточен для базовых задач MVP.

- **Aubio** — Лёгкий и быстрый для BPM и тональности, но менее функционален для энергетики и настроения.

- **FFmpeg** — Простое извлечение длительности и метаданных, но не поддерживает анализ BPM или тональности без дополнительных скриптов.

- **Spotify API** — Готовые данные анализа, но требует интернет-соединения и ограничен треками из Spotify.


## Последствия

- Librosa обеспечивает точный анализ BPM, тональности, энергетики и настроения, уже частично реализован (bpm, key в CSV).

- Mutagen упрощает работу с метаданными и длительностью, поддерживая популярные форматы (MP3, FLAC).

- Простота установки (pip install librosa mutagen) подходит для MVP.

- Librosa требует значительных ресурсов (CPU/RAM) для больших коллекций, что может замедлить сканирование.

- Текущий анализ пока не включает энергетику и настроение в CSV, что требует доработки.

- Совместимость с SQLAlchemy позволяет легко сохранять результаты в Track (bpm, key, duration и др.).


## Статус
**Принято**
